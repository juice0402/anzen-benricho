# 見張り（mihari.yml）

- 何を見張るか：公開（Build and Deploy の main への push・毎月1日と15日の作り直し）と毎週の出典の点検が失敗したら issue、直ったら閉じる。毎朝 5:41（日本時間）に、確認日の期限（C：いちばん古い確認日の90日後が21日以内）と、見る期間に入った国の発表（A 化学物質管理強調月間 第3回の要綱・B1 定期健康診断結果報告書の新しい様式・D 自殺対策強化月間 令和8年度・E 全国労働衛生週間 令和9年度・F 過重労働解消キャンペーン 令和9年度・G 秋季全国火災予防運動 令和9年）を見る。B2（eGFR の有所見の基準）は通達の PDF に出るので Claude の予約タスクに残した
- 3時間ごとにも見る（2026-11-13・#96）：マージの印などが GITHUB_TOKEN で動かした公開は、終わっても workflow_run が来ない（GitHub の決まり）。そこで schedule `53 */3 * * *` の job `latest`（`node scripts/mihari.mjs latest`）が、見張る workflow（`RUNS`。workflow_run の `workflows` と同じ）ごとに main のいちばん新しい完了した実行（cancelled・skipped は飛ばす。`pickLatest`）を、workflow_run と同じ判定（`judge`）に通す。開いた issue へのコメントはその日1回だけ（その日に作った issue にはコメントしない。`notedToday`）。その失敗のあとに閉じられた同じ題の issue があれば作り直さない（`closedAfter`）。毎朝の見張り（watch）は `41 20 * * *` の回だけ（`github.event.schedule` で分ける）。手で動かすと両方動く
- 見るページ：厚労省の報道発表資料の月の一覧（今月と先月）と発表のページ、各種健康診断結果報告書のページ（anzeneisei36/18.html）、r8_jisatsutaisakugekkan.html、過重労働解消キャンペーンのページ（campaign_00004.html）、消防庁の通知の年の一覧（/laws/tutatsu/2027/）。404 は「まだない」、つながらない日は何もしない（7日続いたら mihari の issue）
- issue のラベル：mihari＝知らせるだけ（失敗・公式のページが7日続けて見られない）。night＝夜のまとめ作業が直す（題と本文は Claude の予約タスク「安全衛生の便利帳 発表と確認日の見張り」から写した）。同じ題の issue があれば作らない（night は閉じたものも。開いていればその日1回だけ「まだ続いている」）
- いじるときの注意：判定は `scripts/mihari.mjs`、テストは `tests/mihari.test.mjs`。見る期間と言葉は2027年の1回分なので、済んだら `WATCHES` の期間・題・判定を次の年に直す。workflow の名前（Build and Deploy・出典の点検）を変えたら mihari.yml の `workflows` も直す。試すときは Actions の「見張り」→ Run workflow（dry_run・today で日付を変えられる）
